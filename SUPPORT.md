# Soporte

Vela Bank es un proyecto educativo mantenido por una sola persona. **No hay soporte.**

## Qué no ofrece este proyecto

- No hay SLA, soporte comercial ni atención al cliente.
- No se aceptan depósitos, retiros ni operaciones con dinero real.
- No se atienden consultas sobre cuentas: no existen cuentas reales.
- No hay garantías de disponibilidad ni de conservación de datos.

## Dónde consultar

| Necesidad | Dónde |
| --- | --- |
| Entender el proyecto | Repositorio `docs`: visión, alcance y arquitectura. |
| Conocer el motivo de una decisión | ADRs en `docs/adr`. |
| Reportar un fallo en el código | Issue en el repositorio correspondiente, con su plantilla. |
| Reportar un fallo de seguridad | [SECURITY.md](SECURITY.md), nunca en un issue público. |
| Proponer un cambio | Issue con la plantilla de funcionalidad antes de abrir un pull request. |

## Antes de abrir un issue

1. Busca si ya existe uno abierto o cerrado.
2. Revisa la documentación: muchas preguntas están respondidas en los ADRs.
3. Si es un fallo, indica los pasos para reproducirlo con datos sintéticos.
